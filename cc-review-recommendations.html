Key Takeaways

What matters:
  • The app is 80% of the way to the brief — real data, working 3D projection engine, Orbit V2 (vector search, cinematic zoom, Memory Brief modal) already shipped and live.
  • The single biggest gap: there is no planet. The hub is a faint 46px glow dot; the brief's whole emotional payload (Saturn flyby + rim glow) is absent. One sphere + three compositing tricks + two motion curves ≈ 2 focused days of canvas work.
  • 3 real bugs found: (1) /open on Linux can serve .env-class secrets — fix before sharing any demo login; (2) CRON_JOBS + calendar are hardcoded snapshots from Aug 16–17, already stale; (3) sparse vaults (<3 nodes/zone) collapse the ring — young vaults look broken.
  • Abacus.AI is worth wiring in Phase 1 — but not for DB/embeddings/payments (non-goals). Highest-value: RouteLLM TTS fallback for agent voices, free LLM auto-summaries for the Memory Brief, one-time generated scene assets.
  • Quick wins (~3h, no backend): kill the floor grid → slow rotation + drift → vignette/lens flare → palette tokens → true concentric rings. That's ~70% of the visual gap.

Abacus.AI Integration Roadmap (recommendation-only — no Abacus calls made)

Phase 1 · Quick wins (1–2 days)

  • RouteLLM TTS fallback — elevenlabs / minimax_tts as a /tts rung when relay TTS is down; per-agent fixed voices
  • Brief auto-summaries — gemini-3.5-flash-lite (~$0.0000003/tok) or haiku; cached by path+mtime like embeddings
  • One-time scene assets — flux2_pro nebula backdrop, auth-gate backdrop, og:image; static, zero runtime cost

Phase 2 · Product features (1–2 weeks)

  • Memory-brief postcards — nano_banana 512×512 ink/gold thumbnails from doc title+preview, disk-cached
  • Chat fallback brain — claude-sonnet-5 with agent bio when relay 502s
  • Avatar pipeline — ideogram_character for agent #8 + cloned-agent avatars (monetizable Atrium feature)

Phase 3 · Marketing (optional)

  • Cinematic demo loop — one vejo31_lite / kling clip from the concept art (validate undocumented video endpoint first; keep Higgsfield for production)
  • Hosted demo mirror — sanitized static snapshot on *.abacusai.app free tier for prospects

Abacus non-goals (do not revisit)

  • No Abacus DB / vector store — 0 connectors/datasets, no pgvector; keep vault + Ollama qwen3-embedding (verified: no embedding models in RouteLLM list)
  • No Abacus billing — none exists; stay on Stripe / PayFast / Multica
  • Risks: image/video models are market-rate with null token rates (cache aggressively, per-day caps); undocumented video endpoint (one paid validation call); tier gating; TTS latency → keep as fallback not primary

Recommendation

Decision: Run the ~3h quick-win batch this afternoon (recs 7 → 5 → 8 → 9 → 3) — ~70% of the visual gap with no backend changes and no Abacus spend. Then commit 2 days to the planet + occlusion + drift (recs 1, 2, 4, 6) before the next demo. In parallel, wire Abacus Phase 0–1 (TTS fallback + auto-summaries + scene assets) — highest value-per-credit.
